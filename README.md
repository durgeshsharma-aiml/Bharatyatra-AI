# Bharatyatra AI

Bharatyatra AI is an AI-based smart tourism project designed to help users with travel-related information and assistance.

## Features

- Smart travel assistance
- User registration and login
- Travel dashboard
- Trip management
- Trip details
- Analytics
- User-friendly web interface

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Project Structure

- `app.py` - Main Flask application
- `templates/` - HTML pages
- `static/` - CSS and uploaded files
- `tripsync.db` - SQLite database
